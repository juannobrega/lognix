# Lognix — Documentação

Toda a documentação do Lognix vive aqui, dividida em duas áreas:

| Pasta | Propósito | Quando é escrita |
|-------|-----------|------------------|
| [Planning/](Planning/README.md) | Planejamento completo do sistema: visão, arquitetura, decisões, roadmap. **Nada é construído sem estar mapeado aqui.** | Antes do código. Fase atual. |
| [Software/](Software/README.md) | Documentação do software construído: como rodar, como contribuir, referência de API, guias de operação. | Durante e depois do código. |

## Regras

- **Toda pasta** dentro de `.documentation/` tem um `README.md` explicando o que contém.
- Idioma: português. Identificadores de código, labels e chaves de config em inglês.
- Diagramas em Mermaid dentro do markdown.
- Nomes de pastas e arquivos: **espaço como separador e iniciais maiúsculas** (ex.: `Planning/00 Visão e Escopo.md`). Nunca hífen ou underscore no lugar de espaço.
